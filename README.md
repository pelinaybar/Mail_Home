# YaaniMail Landing Page

A responsive front-end study that recreates a corporate email service landing page using semantic HTML and custom CSS.

![HTML](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)

## Highlights

- Hero section with product-focused messaging
- Responsive navigation and page sections
- Custom visual assets and Türkiye map presentation
- Built without a JavaScript framework

## Run Locally

Clone the repository and open `index.html` in a browser. For a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
